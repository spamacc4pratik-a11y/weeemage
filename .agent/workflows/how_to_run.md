---
description: How to start the Photo Organizer (Frontend + Backend)
---

This project consists of two parts that need to run simultaneously: the backend API and the frontend interface.

### 1. Start the Backend Server
This handles photo storage and the API.
```powershell
cd C:\Users\prate\.gemini\antigravity\scratch\photo-organizer
node server.js
```
*Expected Output:* `Server running on http://localhost:3001`

### 2. Start the Frontend Application
This runs the React interface. OPEN A NEW TERMINAL for this.
```powershell
cd C:\Users\prate\.gemini\antigravity\scratch\photo-organizer
npm run dev
```
*Expected Output:*
```
  VITE vX.X.X  ready in X ms
  ➜  Local:   http://localhost:5173/
```

### 3. Open in Browser
Visit **[http://localhost:5173](http://localhost:5173)**
